# PRD：水印相机

## 1. 产品定位

一款自用、无广告、无弹窗、本地优先的 Android 高画质水印相机。

## 2. 核心痛点与解决方案

- **无广告/会员限制**：完全免费、无弹窗、无账号、隐私透明
- **高画质细节留痕**：配置 CameraX 最高画质拍摄，保留传感器原汁细节
- **马克相机质感**：大字时间（`17:22 | 星期二 / 2026-07-23`）、紫色标题 Tag、字段图标
- **防溢出与自适应**：以图片短边百分比自适应排版，横屏/竖屏均无遮挡、不截断

## 3. 核心功能

### 拍照与高画质
- CameraX 最高画质捕获模式 (`CAPTURE_MODE_MAXIMIZE_QUALITY`)
- 点击对焦与对焦指示圈
- 闪光灯切换（自动/开启/关闭）
- 默认同时保存带水印照片与无水印原图，相册实时广播刷新

### 水印排版与自适应
- 大字时间 + 星期 + 年月日排版
- 紫色标题 Tag (`#7A36D6`)
- 字段图标（📍 地点、☀️ 天气、🌐 坐标、🏔️ 海拔、🧭 方位）
- 短边百分比自适应（大字时间 6.7%、标题 3.3%、正文 2.6%、Logo 12.0%）

### 水印个性化与调整
- **字号三档调节**：小号 (0.5x) / 标准 (1.0x 马克标准) / 大号 (1.5x)
- **透明度四档调节**：100% 不透明 / 85% / 70% / 50% 半透明
- **内置企业 Logo & 自由定制**：内置京湖集团高清透明 Logo，支持关闭 / 内置 Logo / 个人 Logo 切换
- **Logo 3 种位置排版**：文字上方 (Above) / 文字左侧 (Left) / 文字下方 (Below)
- **Logo 6 种染色调色盘**：原色 / 纯白 / 京湖蓝 (`#0072C6`) / 亮金色 (`#FFD700`) / 品牌紫 (`#7A36D6`) / 纯黑 (`#000000`)

### 现场数据与隐私
- 详细门牌/街道地址解析（使用 `getAddressLine(0)` 并剥离“中国”前缀）
- Open-Meteo 天气与 10 分钟 TTL 缓存
- 室内/2D 定位阶段 0.0m 无效海拔自动过滤
- 方位角传感器防抖
- `ExifInterface` 写入 GPS 经纬度及海拔至 JPEG EXIF Header

## 4. 目录与文件名规范

- 带水印图：`Pictures/水印相机/Watermarked/IMG_yyyyMMdd_HHmmss_SSS_WM.jpg`
- 无水印原图：`Pictures/水印相机/Original/IMG_yyyyMMdd_HHmmss_SSS_ORIGINAL.jpg`

## 5. 成功标准

- 拍照无明显挂起，生成带水印图与原图
- 横竖屏拍摄水印 100% 完整显示无截断
- 相册即时可见，照片无明显压缩失真
- 全过程无网络依赖（天气开启除外），无广告弹窗
